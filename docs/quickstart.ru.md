# Быстрый старт и настройка хоста

Пошаговое руководство по первичной подготовке хост-машины, конфигурированию правил udev,
разрешению конфликтов с драйверами ядра, переводу устройств в режим Qualcomm EDL (9008) и проверке соединения.

---

## 1. Подготовка хоста (права доступа к USB)

Для взаимодействия с физической шиной USB без постоянного вызова `sudo` необходимо настроить правила udev и права доступа.

### 1.1. Создание udev-правила

Создайте файл `/etc/udev/rules.d/51-edl.rules`:

```udev
# Qualcomm Snapdragon Emergency Download Mode (9008)
SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="9008", MODE="0666", GROUP="plugdev"
```

Убедитесь, что ваша учетная запись добавлена в группу `plugdev`:

```bash
sudo usermod -aG plugdev "$USER"
```

Примените изменения:

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
```

### 1.2. Конфликт с драйвером qcserial

По умолчанию ядро Linux автоматически сопоставляет чипсеты Qualcomm с модулем `qcserial`, создавая виртуальный TTY-порт
(`/dev/ttyUSB0`), что блокирует доступ к bulk-интерфейсам для библиотеки `libusb`.

Перед запуском выгрузите модуль из ядра:

```bash
sudo rmmod qcserial
```

Чтобы исключить повторный захват порта ядром в будущем, добавьте модуль в черный список:

```bash
echo "blacklist qcserial" | sudo tee /etc/modprobe.d/blacklist-qcserial.conf
```

## 2. Перевод устройства в режим EDL

Для работы утилиты устройство должно определяться на шине USB с идентификатором `05c6:9008`.

### Программные методы (если устройство загружается)

- **Через ADB (из запущенного Android или Linux):**

  ```bash
  make edl-reboot-adb
  # прямой вызов: adb reboot edl
  ```

- **Через Fastboot (из режима Bootloader):**

  ```bash
  make edl-reboot-fastboot
  # прямой вызов: fastboot oem edl или fastboot reboot-edl
  ```

### Аппаратные методы (для USB-модемов и донглов MSM8916 / MSM8909)

1. Отключите устройство от USB-порта.
2. При наличии аппаратной кнопки на плате зажмите её.
3. Если кнопка отсутствует, найдите контрольные точки (**EDL Test Points**) на плате и аккуратно замкните их пинцетом на контакт «земли» (GND).
4. Удерживая замыкание, вставьте устройство в USB-порт компьютера.
5. Через 2–3 секунды разомкните контакты.

### Аппаратные методы (смартфоны и планшеты)

- Выключите аппарат, зажмите аппаратную комбинацию кнопок (обычно `Громкость+` и `Громкость-`) и подключите кабель к ПК.
- Либо используйте специализированный **EDL-кабель** (Deep Flash Cable) с аппаратной кнопкой, замыкающей линию данных D+ на GND в момент подачи питания.

## 3. Проверка подключения на хосте

Проверьте наличие устройства в выводе системной утилиты `lsusb`:

```bash
lsusb | grep 05c6:9008
```

Пример корректного ответа ядра:

```text
Bus 001 Device 014: ID 05c6:9008 Qualcomm, Inc. Gobi Wireless Modem (QDL mode)
```

Также состояние порта можно отследить в системном журнале:

```bash
dmesg | tail -n 20
```

---

## 4. Первый запуск и проверка связи

После перевода устройства в сервисный режим выполните базовое чтение таблицы разделов (GPT):

```bash
make edl-printgpt
```

При успешной установке соединения утилита выполнит:

1. Рукопожатие по протоколу Sahara.
2. Автоматический подбор и загрузку Firehose-программатора в оперативную память.
3. Инициализацию XML-протокола Firehose.
4. Вывод структуры разделов памяти (LUN0, LUN1 и т.д.).

Для получения аппаратной информации о контроллере памяти (тип eMMC/UFS, количество секторов, размер блока):

```bash
make edl-storageinfo
```
